MyExpense Tracker is a desktop-based personal finance management application built with Java and JavaFX. It provides users with a simple, secure, and user-friendly platform to record, categorize, and monitor their daily and recurring expenses.

This project was developed as the final requirement for **BICS 1304 Object-Oriented Programming** at the Kulliyyah of Information & Communication Technology (KICT), IIUM.

##  Features
* **User Authentication:** Secure registration and login system.
* **Expense Management:** Full CRUD (Create, Read, Update, Delete) functionality for transactions.
* **Recurring Expenses:** Support for tracking daily, weekly, or monthly repeating costs using OOP inheritance.
* **Summary Dashboard:** A quick overview of total expenses and transaction counts.
* **File-Based Persistence:** All user credentials and financial records are saved locally (`users.txt`, `expenses.txt`) ensuring data is not lost between sessions.

## Tech Stack
* **Language:** Java
* **GUI Framework:** JavaFX
* **Architecture:** Model-View-Controller (MVC) pattern principles
* **Storage:** Local flat-file storage (CSV format)
